Find Drive files and read, create or update Google Slides. Sign-in happens in your normal browser; Beam never needs your Google password.
Google setup instructions
  1. Create a project in Google Cloud.
  2. Enable the Google Drive API and Google Slides API.
  3. Configure Google Auth Platform branding and consent. For a personal app, use Testing and add your own Google account as a test user.
  4. Create an OAuth client with application type Web application. Register {{ callback_url }} as an authorized redirect URI. Download its JSON file.
  5. Import that file here, click Connect Google and approve the requested permissions in Google’s browser window.
The requested permissions allow reading Drive files, editing Slides and identifying the connected account. Google’s consent screen shows the scopes. Testing-mode apps can require reconnection.
